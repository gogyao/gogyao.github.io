# SVG sources

The C#, PostgreSQL, Microsoft SQL Server, and Python SVGs are original assets
downloaded from [Devicon](https://github.com/devicons/devicon), under the included
`DEVICON-LICENSE`. Their paths are used directly for the 3D technology signs.

- `csharp.svg`: `icons/csharp/csharp-original.svg`
- `postgresql.svg`: `icons/postgresql/postgresql-original.svg`
- `mssql.svg`: `icons/microsoftsqlserver/microsoftsqlserver-original.svg`
- `python.svg`: `icons/python/python-original.svg`

`ai-tools.svg` is the CPU icon from [Lucide](https://github.com/lucide-icons/lucide/blob/main/icons/cpu.svg),
recolored to match the interface. It represents a category, rather than an AI brand.
The existing React, TypeScript, Tailwind, Figma, and Motion SVGs remain in use.
